# Multi-Session Map Evidence

本目录保存多会话候选地图的清单快照、参考轨迹、跨圈约束和 held-out 评测报告。候选由
163 个 canonical 子图和 38 个 support 外观变体组成；完整 `submaps/` 和原始点云不在
源码仓库中分发。

严格因果桌面回放结果：

- 41/41 个有效锚点低于 0.10 m；
- 平均误差 0.0349 m；
- P95 0.0694 m；
- 最大误差 0.0929 m；
- 路线覆盖率 100%，无索引倒退或异常跳变。

该结果只资格化桌面 held-out LiDAR 地图重复定位，不代表 AGX 在线定位或测量意义的绝对
精度。完整运行地图需要使用 `deployment.mapping` 工具从采集数据重新生成。
